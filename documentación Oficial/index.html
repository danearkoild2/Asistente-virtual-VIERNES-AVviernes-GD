Requisitos Mínimos y Dependencias

Especificaciones técnicas recomendadas para ejecutar Viernes con fluidez y mínimo consumo.

Requisitos Mínimos

  • SO: Windows 10/11 (64-bit), Linux o macOS
  • Python: 3.11 o 3.12 (recomendado 3.12)
  • CPU: 4 núcleos (Intel i5 / Ryzen 5 o superior)
  • RAM: 8 GB mínimo (16 GB si usas Coqui XTTS-v2 o modelos locales)
  • Audio: Micrófono y altavoces/audífonos
  • Red: Conexión a internet para Gemini Live API

Dependencias Principales

  • PyQt6 & PyQt6-WebEngine (HUD, Live2D, TV Web, PayPal)
  • google-genai (Motor conversacional Gemini Live)
  • sounddevice, numpy, miniaudio, edge-tts
  • requests, beautifulsoup4, psutil
  • opencv-python (Visión en tiempo real)
  • adblock (Brave Rust AdBlock para TV y Deportes)
  • Opcionales: coqui-tts, torch, torchaudio (XTTS-v2 local)

Instalador Oficial (Groovi Developer)

Configura dependencias, nombre, API Key de Gemini, voz y skin en minutos.

git clone https://github.com/groovideveloper/viernes.git
cd viernes
py -3.12 installer.py
# O en Windows haz doble clic en: instalar_viernes.bat

APIs: Obligatoria vs Opcionales

Solo una clave API es obligatoria para arrancar Viernes; todas las demás son opcionales.

ElevenLabs Opcional Síntesis de voz ultrarrápida Flash v2.5 (~200 ms) elevenlabs.io
SerpAPI Opcional Búsqueda web avanzada y vuelos en tiempo real serpapi.com
OpenWeather Opcional Widget de clima local y pronóstico extendido openweathermap.org
Spotify Opcional Control inteligente de reproducción y listas developer.spotify.com
Home Assistant Opcional Control domótico LAN avanzado Instancia local (Token de larga duración)
  1. Ingresa a https://aistudio.google.com/apikey e inicia sesión con tu cuenta de Google.
  2. Haz clic en "Create API key" y selecciona o crea un proyecto de Google Cloud.
  3. Copia la clave generada (empieza por AIza...).
  4. Pégala directamente en el Instalador Oficial de Viernes (installer.py) o en ⚙ → Claves API dentro del HUD.

Modelos Live2D y Cómo Instalar Nuevos

Motor PixiJS + Cubism Core embebido en Qt WebEngine con sincronización labial, expresiones y skins intercambiables.

Arquitectura Live2D Nativa

Viernes renderiza el modelo Edith (y cualquier modelo compatible con Cubism 2/3/4) en core/live2d/ mediante skin_manager.py, reaccionando automáticamente a la amplitud de voz, gestos e interrupciones.

Cómo Instalar un Modelo Live2D Nuevo

  1. Descarga un modelo Live2D completo (que contenga *.model3.json, texturas .png y físicas/moc3).
  2. Coloca la carpeta del modelo dentro de core/live2d/skins/<nombre_del_modelo>/ (o abre la carpeta desde Presencia ▾ → Abrir carpeta de skins).
  3. En el HUD de Viernes abre Presencia ▾ → Skins Live2D y selecciona tu nuevo modelo al instante.

Motores de Voz (TTS) Disponibles

Elige entre latencia en la nube o síntesis local gratuita con clonación de voz.

Motores Integrados

  • Gemini Live (Nativo): 30 voces integradas + modulación acústica sin costo adicional a tu API.
  • Edge Neural: Voces neurales gratuitas de Microsoft en español (MX, AR, ES, CO, CR) sin GPU.
  • ElevenLabs Flash v2.5: Streaming de ultra baja latencia (~200 ms).
  • Coqui XTTS-v2 (Local): Gratuito y offline vía idiap/coqui-ai-TTS con clonación de voz usando un .wav de 6–15s.

Cambio en Caliente

Puedes cambiar de motor desde ⚙ → Personalizar asistente y voz o directamente durante la instalación inicial en installer.py. Si un motor local falla, Viernes cambia automáticamente a Edge Neural como respaldo.

Clean Your TV (Limpieza Segura para Android TV)

Integración nativa de udhaykumarbala/cleanyourtv-app y Gathin23/cleanyourtv.

Flujo Guiado en 3 Pasos (100% Reversible)

  1. Conectar: Escanea tu Wi-Fi en busca de Android TVs (puerto ADB 5555) y te guía paso a paso con el control remoto.
  2. Analizar: Cruza los paquetes del TV contra 473 perfiles comunitarios clasificándolos en anuncios, telemetría y bloatware.
  3. Limpiar y Restaurar: Guarda un punto de restauración automático en config/cleanyourtv_backups/ y desactiva de forma segura con pm disable-user --user 0.

Arquitectura del Sistema, Seguridad y Atajos

Cómo se organiza Viernes internamente, cómo protege tus credenciales y cómo operarlo al instante.

Estructura Modular

  • actions/ — 53 módulos de acción de alto nivel
  • plugins/ — 41 plugins extensibles + _template.py
  • core/ — 60+ motores (LLM, TTS/STT, Live2D, TV, Radio, CleanYourTV, HUD)
  • memory/ — Memoria a largo plazo, conocimiento de libros y config
  • dashboard/ & app/ — Panel web remoto y App Android
  • security/ — Bóveda cifrada y validación de claves

Seguridad, Cifrado y Confirmación

  • Cifrado local de credenciales con cryptography (config/api_keys.json)
  • Módulo core/confirm.py para confirmar acciones destructivas antes de ejecutarlas
  • Módulo core/undo.py y send2trash para revertir operaciones
  • Biometría vocal (voice_security.py) y limpieza de secretos para GitHub

Atajos y Modos del HUD

  • F4: Activar / silenciar micrófono al instante
  • Botón 🎛️ HUD Studio: Personalización total de temas, colores, fuentes y fondos
  • Botón 🎭 Presencia: Alterna Live2D, VRM 3D, Holograma o modo compacto
  • Botón 💛 Donar · PayPal: Acceso directo en la esquina inferior derecha del HUD
