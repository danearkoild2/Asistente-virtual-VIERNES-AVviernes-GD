=====================================================
CARPETA DE MODELOS / SKINS LIVE2D (MARK LV / VIERNES)
=====================================================

Para agregar un nuevo personaje o skin Live2D:
1. Crea una carpeta aqui con el nombre del personaje (ejemplo: 'Hiyori', 'Miku', 'Edith Maid', etc.).
2. Pega dentro de esa carpeta todos los archivos del modelo:
   - Archivo .model3.json
   - Archivo .moc3
   - Carpeta de texturas (textures/)
   - Archivos de fisica o expresiones (.physics3.json, etc.)

3. En el menu de Avatar (icono de controles en el header), aparecera automaticamente
   el selector de Personaje con tu nueva skin lista para usar con toda la fisica,
   sincronizacion de voz y seguimiento de mirada!
